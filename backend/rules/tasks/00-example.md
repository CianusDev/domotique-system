# Task 00 : Template de tâche

Ce fichier sert de modèle pour les tâches d'implémentation.

## Format d'une tâche

```markdown
# Task XX : Titre de la tâche

## Contexte
Pourquoi cette tâche est nécessaire.

## Objectif
Ce qui doit être accompli précisément.

## Critères d'acceptation
- [ ] Critère 1
- [ ] Critère 2

## Fichiers concernés
- `src/module/fichier.ts`

## Notes
Contraintes particulières, points d'attention, liens vers la doc.
```
